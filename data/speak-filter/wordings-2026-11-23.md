# Speak filter wordings, 2026-11-23

Eight wordings of the speak filter's rules compared on the scenario set: the owner's original,
three rewordings each of `unfinished_thought` and `mentioned_not_asked`, and one of
`to_other_participant` (`tools/loadtest/fixtures/speak_filter_candidates.json`). Each candidate
changes one rule. The set now has 63 scenarios: the 52 from before plus 11 `hard_silent`.
The filter now includes the look-back (`owed_reply`) and tells the classifier about silence.
Every rule was asked at 0.5 and swept from the recorded probabilities. One paid run, made by
hand from a laptop:

```
python -m meetlab_loadtest.speak_filter_replay --i-understand-this-costs-money --max-calls 600 \
    --runs 1 --threshold 0.5 --candidates tools/loadtest/fixtures/speak_filter_candidates.json \
    --repeat original --env-file .env --usd-per-1m-input 0.10 --usd-per-1m-output 0.50
```

- Model `gpt-6-luna` (Pipecat's `OpenAIDecisionsClassifier` default). 432 classifier calls
  (48 per candidate run, 8 candidates plus one repeat of `original`), 0 errors.
- 383,108 input tokens, 0 output tokens: **US$0.04** at the price given on the command line.
- 15 of the 63 scenarios never reach the classifier: 11 called by name, 3 owed a reply
  (`bqh-01..03`), and `ctl-02`, which has no rule.
- Repeatability: in the repeat of `original`, every probability of every scenario was the same
  as in the first run (largest spread 0.00, no decision changed). The probabilities `original`
  shares with the first measurement are also unchanged, except where the silence sentence was
  added (`sil-*`).
